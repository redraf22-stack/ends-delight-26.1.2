# End's Delight — порт на Minecraft 26.1.2 (Fabric)

**Неофициальная сборка.** Порт мода **End's Delight** автора **FoggyHillside** (MIT) на **Minecraft 26.1.2**
(Fabric, Loom 1.17, Java 25, mojmap). Оригинал — аддон к Farmer's Delight о кухне Края.

## Что добавляет

Еда и готовка Края: мясо дракона и шалкера, эндер-мит, колбаски, сушёные цветы хоруса, чаи и вина из хоруса,
пироги и «жаркое». Есть своя **печь энда** (`end_stove`), которая работает по правилам Farmer's Delight:
на ней жарят, на неё ставят кастрюлю или сковороду.

## Установка

1. **Minecraft 26.1.2**, **Fabric Loader 0.19.5+**, **Java 25**.
2. Нужны отдельно:
   - **Fabric API 0.155.2+26.1.2**
   - **Farmer's Delight Refabricated 26.1-3.6.30**
3. В `mods` положить `ends_delight-26.1.2-1.0.0.jar`.

С [Hands-On Delight для 26.1.2](https://github.com/redraf22-stack/handson-delight-26.1.2/releases) печь энда
автоматически становится интерактивной станцией (гриль на 6 мест, переворот кусков, книга рецептов), а рецепты резки
и варки этого мода появляются в книгах доски и котла.

## Сборка

```bash
gradle build --offline      # нужен JDK 25
```
